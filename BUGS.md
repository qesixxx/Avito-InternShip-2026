**Bug Report #01:** Возможность создания объявления с отрицательной ценой
**Приоритет**: Critical (P1)
**Окружение**: OS: Windows 10 Pro, Инструмент: Postman Version 12.4.6, URL: https://qa-internship.avito.com
**Эндпоинт**: POST /api/1/item
**Описание**: Сервер позволяет создать объявление, даже если в поле price передано отрицательное целое число. Валидация на стороне бэкенда проверяет тип данных, но не проверяет логическую допустимость значения (цена >=0)
**Шаги воспроизведения**:
1. В теле запроса JSON указать"price": -1
2. Отправить POST-запрос по эндпоинту /api/1/item
**Фактический результат**: Статус-код: 200 ОК. Объявление успешно создано. Ответ status: "Сохранили объявление - {id}".
**Ожидаемый результат**: Статус-код: 400 Bad Request. Сообщение об ошибке: "Цена не может быть отрицательной".

**Bug Report #02**: Возможность создания объявления с названием состоящим только из пробелов.
**Приоритет**: Medium (P3)/Low
**Окружение**:  OS: Windows 10 Pro, Инструмент: Postman Version 12.4.6, URL: https://qa-internship.avito.com
**Эндпоинт**: POST /api/1/item
**Описание**: Сервер принимает строку, состоящую только из пробельных символов, как валидное значение для обязательного поля name. В результате создается объявление без видимого заголовка.
**Шаги воспроизведения**:
1. В теле JSON указать название из нескольких пробелов "name" = "   ", остальные обязательные поля заполнить
2. Отправить POST-запрос на эндпоинт
3. Получить ответ от сервера.
**Фактический результат**: Статус-код: 200 ОК. Объявление успешно создано, возвращен ID
**Ожидаемый результат**: Статус-код 400 Bad Request. Уведомление об ошибке: "Название не может быть пустым или состоять только из пробелов".

**Bug Report #3**: Отсутствие ограничение на максимальную длину поля "name".
**Приоритет**: Medium (P3)/Low
**Окружение**: OS: Windows 10 Pro, Инструмент: Postman Version 12.4.6, URL: https://qa-internship.avito.com
**Эндпоинт**: POST /api/1/item
**Описание**: Сервер позволяет создавать объявления с длиной заголовка более 100 символов, что нарушает стандартные требования к контенту и может приводить к некорректному отображению карточки товара в интерфейсе.
**Шаги воспроизведения:**
1. В поле name JSON-тела передать строку длиной 101 символ (предположим, что ограничение 100), например 'A'*101
2. Остальные поля заполнить валидными данными
3. Выполнить POST-запрос по эндпоинту
4. Получить ответ сервера
**Фактический результат**: Статус-код: 200 ОК, объявление создано
**Ожидаемый результат**: Статус 400 Bad Request. Ошибка валидации длины.

**Bug Report #4**: Блокировка создания объявления при нулевых значениях в statistics.
**Приоритет**: High (P2), блокирует основной функционал (создание объявлений)
**Окружение**: OS: Windows 10 Pro, Инструмент: Postman Version 12.4.6, URL: https://qa-internship.avito.com
**Эндпоинт**: POST /api/1/item
**Описание:** Сервер некорректно обрабатывает поле statistics. При передаче числового значения 0 в обязательные поля likes, viewCount, contacts, система ошибочно интерпретирует их как "отсутствующие".
**Шаги воспроизведения**:
1. Заполнить все обязательные поля, в объекте statistics установить 0 для всех параметров "likes": 0, "viewCount": 0, "contacts": 0.
2. Отправить POST-запрос по эндпоинту
3. Получить ответ сервера
**Фактический результат**:  Сервер возвращает статус 400 Bad Request. Тело ответа: 
`{`
    `"result": {`
        `"message": "поле likes обязательно",`
        `"messages": {}`
    `},`
    `"status": "400"`
`}`
**Ожидаемый результат**: Статус: 200 ОК. Объявление успешно создано. Число 0 является валидным значениям для счетчиков.

**Bug Report #5**:  Отсутствие валидации XSS-инъекций в поле "name"
**Приоритет**: Critical (P1) (риск безопасности)
**Окружение**: OS: Windows 10 Pro, Инструмент: Postman Version 12.4.6, URL: https://qa-internship.avito.com
**Эндпоинт**: POST /api/1/item
**Описание**: Сервер принимает и сохраняет исполняемый JavaScript-код в обязательном поле name. Создает уязвимость.
**Шаги воспроизведения**:
1. Сформировать POST-запрос, внедрив в поле name исполняемый JavaScript-код.
2. Отправить запрос на сервер
**Фактический результат**: Статус-код 200 ОК. Объявление успешно создано, вредоносный код сохранен в базе данных.
**Ожидаемый результат**: 
Статус-код: 400 Bad Request. Ошибка валидации. Сервер должен отклонять запросы с HTML/JS тегами
